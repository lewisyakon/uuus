ns3提供的mpi实现文件主要是mpi-interface、distributed-simulator-impl、mpi-receiver这三个文件中，其中mpi-interface具体对应两种算法的实现GrantedTimeWindow和NullMessage，unison结合使用的是前者,interface即ns3和mpi之间的接口，继承parallel-communication-interface
------------------------------------------------------------------------------
MPI中的阻塞发送和接收指调用MPI_Send/Recv时暂停进程执行直到发送和接收操作做完
非阻塞发送和接收指不暂停进程，通过MPI_Request句柄记录其是否完成，通过周期性调用MPI_Testany检查是否有数据到达并处理即可

MPI_Comm通信器本质是一组参与MPI程序的进程组以及一个允许这些进程之间进行通信的上下文
------------------------------------------------------------------------------
parallel-communication-interface.h：
确立一个标准接口，用于管理ns3模拟内核与其底层mpi之间的交互，是一个纯虚基类，它不能被实例化，其核心作用是抽象出ns3在并行环境中进行进程间通信所需的所有操作
Enable()启用并行通信层，初始化MPI环境，或使用一个已经存在的MPI_Comm
Disable()、Destroy()、GetSystemId()、GetSize()、GetCommunicator()
SendPacket()发送一个数据包给另一个并行进程，四个参数，数据包packet、理论接收时间rxTime插入事件堆、接收节点node、调度设备dev
------------------------------------------------------------------------------
GrantedTimeWindowMpiInterface：
g_rxCount/g_txCount记录总接收/总发送的数据包数量
g_pendingTx待处理的非阻塞发送请求列表
g_requests/g_pRxBuffers管理非阻塞接收的MPI请求和数据缓冲区

继承parallel-communication-interface.h，实现对应的虚方法
Enable()调底层MPI_Init启动MPI环境，复制传入的Communicator确保ns3库在隔离的通信上下文中操作，获取对应Rank和Size，为每个Rank预先分配g_Rxbuffer，调用MPI_Irecv发布一个非阻塞接收操作，意味着MPI系统现在正监听来自任意源的消息，一旦数据到达就写入对于buffer

SendPacket()创建SentBuffer并加到g_pendingTx，确定好四个参数后调用MPI_Isend发送整个buffer并接收一个MPI_Request跟踪发送状态，更新g_txCount

ReceiveMessages()MPI_Testany检查g_requests是否接收完成，更新g_rxCount，读出对应参数，找到对应设备的MpiReceiver对象，根据rxTime调度事件，再次调用MPI_Irecv监听任意源的消息

TestSendComplete()检查g_pendingTx是否有已完成的非阻塞发送，对每个buffer调用MPI_Test检查是否完成，并释放对应buffer

SentBuffer辅助类，将发送的数据缓冲区m_buffer和对应的MPI请求句柄MPI_Request封装在一起，当需要发送一个跨进程数据包时，使用MPI_Isend非阻塞发送，它会返回一个MPI_Request表示发送请求但尚未完成，SentBuffer会放入g_pendingTx列表
------------------------------------------------------------------------------
distributed-simulator-impl：
PDES模型的具体执行
每次同步周期开始时，每个Rank创建一个LbtsMessage报告本地状态，包括m_smallestTime最早的下一个事件的时间辍、m_txCount/m_rxCount用来检测是否还有跨进程的数据包已发送但还未接收、m_isFinished报告本地是否没有事件执行了，所有LbtsMessage通过一次AllReduce发给其它所有进程，计算m_grantedTime，然后每个进程根据窗口值运行本地事件

CaculateLookAhead()计算本地lookahead，所有rank执行一次MPI_AllReduce确定一个全局最大的lookahead值

Run()先调用CaculateLookAhead()确定初始时间窗口，然后while循环直到所有事件处理完，取事件开始做，如果事件时间辍大于m_grantedTime则触发同步，先调用GrantedTimeWindowInterface::ReceiveMessages处理跨进程消息，再调用GrantedTimeWindowInterface::TestSendComplete清理已完成的跨进程消息，
创建本地LbtsMessage执行MPI_Allgather计算新的时间窗口
如果时间辍小于m_grantedTime则调用ProcessOneEvent()
------------------------------------------------------------------------------
mpi-receiver：
为Netdevice提供一个统一的MPI接收接口，根据rxTime调用对应netdevice的receive接收跨进程的packet
------------------------------------------------------------------------------
fat-tree-mpi：
节点在create时将其分给不同的rank
设置初始流量时需要判断该节点是否在当前进程的LP中，避免重复安装


多节点mpi跑通步骤：
1.利用docker控制节点版本相同
2.docker内ssh免密连接，需要在Dockerfile使用host模式(实际上不能用，不然在一侧容器连到另一侧时实际上进的是另一侧的宿主机运行，需要加一个启动脚本，才能进到对应的容器内运行)，即容器和宿主机使用相同ip
  使用的密钥可以是宿主机原本就有的，把原有的密钥挂载到容器内指定路径，写好config文件即可，这个config文件可以是NFS里的挂载到容器里
 其中需要注意的问题是ssh免密互连对文件权限要求很高，authorized_keys必须是连接的用户所有且权限必须是600
  直接挂载宿主机下的~/.ssh整个文件夹，并且在创建容器时可以把宿主机的ssh-agent也挂载进去
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_personal
3.利用mpirun跑多节点多进程，要求不能是root用户，在Dockerfile创建好新用户，且这个用户的uid要和两个宿主机所用uid最好四个都是相同的，因为要用NFS共享文件夹和ssh互连
4.NFS共享文件夹的客户端对于其中的文件，读权限是根据NFS服务器端该文件夹的所有者的uid决定，写权限根据映射规则决定，即客户端的uid映射成服务器上的什么uid
  sudo mount -t nfs lewis:/mnt/nfs/cloud /mnt/nfs/cloud
5.mpirun要求ssh免密互连是建立连接，对应的进程之间通信选用的端口是底层动态选择，容器内有一些虚拟ip和端口会影响其选通信端口，要通过--mca btl_tcp_if_include 10.201.0.0/16限制所选ip范围

#!/bin/sh
set -eu

host="$(hostname -s 2>/dev/null || hostname)"

case "$host" in
  Super-Server|lab206)
    container="hybrid-206"
    ;;
  user-Super-Server|lab254)
    container="hybrid-254"
    ;;
  seu-Precision-7920-Tower|lab188)
    container="hybrid-188"
    ;;
  user-System-Product-Name|lab133)
    container="hybrid-133"
    ;;
  *)
    echo "mpi-docker-agent: unsupported host: $host" >&2
    exit 2
    ;;
esac

DOCKER_BIN="${DOCKER_BIN:-/usr/bin/docker}"
if [ ! -x "$DOCKER_BIN" ]; then
  DOCKER_BIN="$(command -v docker || true)"
fi

if [ -z "${DOCKER_BIN:-}" ] || [ ! -x "$DOCKER_BIN" ]; then
  echo "mpi-docker-agent: docker not found" >&2
  exit 3
fi

if ! "$DOCKER_BIN" inspect -f '{{.State.Running}}' "$container" 2>/dev/null | grep -qx true; then
  echo "mpi-docker-agent: container $container is not running on $host" >&2
  exit 4
fi

exec "$DOCKER_BIN" exec -i "$container" "$@"

sudo chmod +x /usr/local/bin/mpi-docker-agent
